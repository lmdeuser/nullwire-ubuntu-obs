## TDD: Qt Shader Baker

obs3.test5 прошла проверку `gperf`, но CMake не нашёл QSB. Содержимое Ubuntu-пакета `qt6-shader-baker` подтвердило фактический путь `/usr/lib/qt6/bin/qsb`. Тест связал его с `QSB_EXECUTABLE` в `debian/rules`: до исправления он упал, после явной передачи пути прошёл. Все 34 теста зелёные. obs3.test6 прошла конфигурацию и перешла к компиляции клиента.

## TDD: QAccessible и Qt 6.10

obs3.test6 остановилась на `QAccessible::Attribute::Orientation`: официальная документация Qt относит этот атрибут к Qt 6.11, а в Ubuntu 26.04 используется Qt 6.10. Focused compile test воспроизвёл ошибку на точных методах с API Qt 6.10, затем проверил version guard на Qt 6.10 и 6.11. Патч применяется к реальному исходнику 7.4.1 с `--fuzz=0`; все 35 тестов прошли. obs3.test7 дошла до 94% компиляции клиента.

## TDD: Thanos без приватного Qt API

obs3.test7 обнаружила обращение `_renderer->failed()` к неполному типу в animation lambda: при `DESKTOP_APP_DISABLE_PRIVATE_QT_API` renderer только forward-declared и указатель остаётся null. Focused test воспроизвёл ошибку до патча и проверил обе конфигурации после добавления такого же guard, как у объявления renderer. Патч применён к реальному исходнику с `--fuzz=0`; все 36 тестов зелёные. obs3.test8 скомпилировала 100% клиента.

## TDD: компоновка без LTO

На финальной компоновке obs3.test8 процесс `lto1` был остановлен сигналом `Killed`. Тест с настоящим `dpkg-buildflags` сначала подтвердил наличие `-flto=auto`, а после добавления `optimize=-lto` проверил его отсутствие. obs3.test9 прошла границу LTO.

## TDD: размер debug-секций
